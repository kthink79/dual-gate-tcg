# 🎴 듀얼 게이트: 이계의 문 (Dual Gate TCG)

> **현실–이세계 크로스 모바일 TCG 안드로이드 프로젝트**  
> 기획서 초안 v0.1 및 3단 비주얼(전투/사복/데이트) 70종 카드 구현 베이스라인 (Kotlin + Jetpack Compose)

---

## 🎯 게임 기획 및 핵심 메커니즘

1. **현실 봉인 팩 습득 프롤로그 & 스타팅 3인방 계약**
   - 일상 골목길에서 주운 의문의 봉인 카드팩을 개봉하며 스타팅 3인방(성기사 아우렐리아, 건슬링어 베리티, 무녀 히스이)과 계약합니다.
   - 언제든 원하는 시점에 차원 게이트를 통해 이세계로 다이브하여 세계를 구원합니다.

2. **현실 소환 교감 ↔ 이세계 전략 배틀 듀얼 월드 순환 루프**
   - **현실 소환 모드**: 갑옷을 벗고 [일상 사복 큐트] 또는 [매혹적인 데이트 룩]을 착용한 파트너와 일상 교감을 나누어 호감도(Bond)를 육성합니다.
   - **호감도 MAX 달성 시**: 전투 시 발동되는 강력한 **'페어 얼티밋 오의' (+25% 데미지 증폭)** 가 영구 개방됩니다.
   - **이세계 원정 모드**: 풀 무장 TCG 턴제 배틀을 클리어하여 EXP를 획득하고, 카드의 기본 능력치(ATK·DEF·HP)를 영구 성장시킵니다.

3. **속성 상성 및 전열/후열 턴제 카드 배틀**
   - **3원소 삼각 순환**: 화염(FIRE) → 바람(WIND) → 빙결(ICE) → 화염 (+30% 증폭 / -20% 경감)
   - **2극원소 상호 카운터**: 빛(LIGHT) ↔ 어둠(DARK) (+50% 극딜 상호 카운터)
   - 전열 3슬롯 / 후열 2슬롯 배치 및 마나 코스트 운영

4. **카드 합성 및 5성 한계 돌파 & 3슬롯 장비 장착**
   - 동일 카드 합성 시 성급 상승(최대 5성 한계 돌파, 성급당 능력치 +20% 스케일링)
   - 무기·방어구·아티팩트 3슬롯 장비 시스템

5. **덱 구성 — 유일 카드 원칙 (기획서 v0.3 §7.3)**
   - **캐릭터 20장**(서로 다른 20명 각 1장 — 동일 캐릭터 2장 이상 편성 불가) + **장비/스펠 10장**(동일 카드 최대 3장) = 메인 덱 30장
   - `DeckEngine.validateDeck`이 총 30장·캐릭터 유일성·장비/스펠 3장 제한·표준 구성을 검증합니다.

## 🛠 기술 스택 및 아키텍처

- **플랫폼**: Android (Min SDK 26, Target SDK 35)
- **프로그래밍 언어**: Kotlin 2.0+ (선정 사유: Android 네이티브 표준, 고성능 타입 안정성, 반응형 코루틴)
- **UI 프레임워크**: Jetpack Compose + Material 3
- **아키텍처**: Clean Architecture + MVVM
- **검증**: JUnit 4 / AndroidX Test

```
com.game.tcg
├── core
│   ├── model          # TcgCard, Element, VisualState, BattleSlot, PlayerDeck
│   └── engine         # 전투(BattleEngine), 합성(SynthesisEngine), 크로스루프(DualWorldEngine)
├── ui                 # Jetpack Compose UI 및 시뮬레이션 컴포넌트
└── MainActivity.kt    # 메인 액티비티 진입점
```

## ✨ 추가 시나리오 & UI 확장 (v0.4)

기존 UI·테스트를 유지한 채 핵심 컨셉을 살리는 시나리오 3종과 전용 UI를 추가했습니다. 단위 테스트는 68 → **83개**로 확장되었습니다.

### 1. 「기억의 잔향: 환생한 파트너와의 재회」
- 마왕전에서 사망해 환생 풀에 들어간 캐릭터를 재획득하면 단순 복구되지 않고 **`isMemoryReset = true`(기억 초기화)** 와 **`memoryFragments`(0/3)** 가 부여됩니다 (`RoguelikeLifecycleEngine.buildReacquiredCard`).
- 도감·서약과 현실 교감 탭에 **「기억이 지워진 동료」 배지 + 기억 파편 게이지(0/3)** 카드가 표시됩니다.
- **현실 교감**과 **이계 전투 승리**로 파편을 모으면 **「기억의 조각 회상」 특별 이벤트 대화**가 열리고, 원본 스탯 +15% 보너스와 기억 복원(호감도 +20, 초기화 해제)이 적용됩니다 (`MemoryRecallEngine`).
- UI: `CollectionScreen` 기억 파편 카드/회상 대화, `RealWorldScreen` 기억의 잔향 교감.

### 2. 「신뢰의 균열: 마왕의 홀림을 눈치챈 파트너」
- `[홀림]` 스택이 **2 이상**이면 시나리오 탭에 **긴급 교차 이벤트 카드**가 활성화됩니다. 아우렐리아: "요즘 눈빛이 흔들리고 있어요… 그 카페의 릴리라는 사람 때문인가요?"
- 선택지 A *"솔직히 털어놓고 함께 정화한다"* → **성수 없이 홀림 -1 · 호감도 +10**
- 선택지 B *"아무 일 아니라고 숨긴다"* → **홀림 +1 · 호감도 -15 · 다음 전투 전열 방어 -10%** (전투 로그에 `전열 결손 방어 -10%` 표기)
- UI: `ScenarioScreen` 교차 이벤트 카드, `TcgGameViewModel.resolveTrustRift` (`TrustRiftEngine`).

### 3. 「페어 얼티밋 오의 컷인 & 제2장 프롤로그(제1군단장 그림자 기사)」
- 전투 화면(`BattleScreen`)에서 **아군 2명 이상 생존 + 마나 3 이상**일 때 **「⚡ 페어 얼티밋 오의 발동」** 버튼이 열리고, 황금·네온 그라디언트 **컷인 배너**와 전투 로그가 출력됩니다 (전투당 1회, 3인 이상 생존 시 배율 상승 — `PairUltimateEngine`).
- 시나리오 탭 5화 이후 **「제2장 프롤로그: 제1군단장 '그림자 기사' 전초전」** 노드가 열려 다음 여정(HP 32,000 / ATK 3,400)을 시작할 수 있습니다 (`ChapterTwoScript`).
